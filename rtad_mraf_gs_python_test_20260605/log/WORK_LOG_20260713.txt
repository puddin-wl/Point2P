======================================================================
三、SLM 大相位位移补偿
======================================================================

确认用户所说的位移补偿不是改变输入 Gaussian beam，也不是只增加 blaze，而是把已经生成的“大相位”相对固定光束整体平移。

相关脚本已经整理进测试目录：

shift_sweep_slm.py
verify_shift_sweep.py
add_blaze_grating.py

核心位移逻辑：

ph_shifted = shift_phase(phase, sy, sx)

其本质是：

np.roll(np.roll(phase, shift_y_px, axis=0), shift_x_px, axis=1)

完整顺序为：

原始 phase
-> 整体 X/Y 像素位移
-> 添加 blaze
-> 导出 SLM 文件

需要继续区分三个概念：

shift_phase：SLM 安装位置/相位相对光束的位置补偿。
add_blaze：通过线性相位坡度改变焦斑偏转。
swap_phase_xy：MATLAB/Python 读取相位时的轴向约定，不是 SLM 位置补偿。

相关说明文件：
E:\program\Point2P\rtad_mraf_gs_python_test_20260605\README_SLM_SHIFT.md

======================================================================
五、raised-cosine 参数和尺寸换算
======================================================================

项目中的目标首先按 intensity 定义：

C(u) = 1，u <= u0
C(u) = 0.5 * (1 + cos(pi*(u-u0)/(u1-u0)))，u0 < u < u1
C(u) = 0，u >= u1

其中：

u0 = D50/2 - delta
u1 = D50/2 + delta

当前使用 delta_x=15 um、delta_y=8 um。
今天没有找到可以严格证明 15/8 最初来源的厂商参数记录，因此暂时保留现值，不再追溯或修改。

由 raised-cosine 解析式可得：

D90 = D50 - 1.180668941 * delta
D13.5 = D50 + 1.040671278 * delta
(D13.5 - D90)/2 = 1.110670110 * delta

这也解释了此前讨论的三个系数：

1.18067：size50 到 size90 的换算系数。
1.04067：size50 到 size13.5 的换算系数。
1.11067：单侧 size90 到 size13.5 的过渡宽度系数。

本轮选择“不等比例扩大”方案，即 delta_x/delta_y 仍保持 15/8 um，只向外调整 W50/H50。

若只按连续 raised-cosine 反推，使理论 size90=330 x 120 um，则：

W50 = 330 + 1.180668941*15 = 347.710034 um
H50 = 120 + 1.180668941*8 = 129.445352 um
