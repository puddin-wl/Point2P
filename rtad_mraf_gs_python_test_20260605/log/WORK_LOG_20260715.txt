八、仿真与实验 86.5% 能量尺寸差异分析
======================================================================

V2 仿真与现场结果：

仿真 86.5%：X=360.00 um，Y=125.00 um
实验 86.5%：X=324.72 um，Y=118.08 um

不能把该差异简单归因于 BeamGage 的 86.5% 算法。对 50% 轮廓宽度进行比较：

仿真 size50：X=374.03 um，Y=137.19 um
实验 size50：X=347.73 um，Y=130.17 um

实验/仿真的 size50 比例：

X=0.9297，即实际几何宽度缩小约 7.03%
Y=0.9488，即实际几何高度缩小约 5.12%

实验/仿真的 86.5% 比例：

X=0.9020，即缩小约 9.80%
Y=0.9446，即缩小约 5.54%

按 size50 的几何缩放比例修正仿真 86.5% 尺寸后：

X 预测约 334.68 um，实验为 324.72 um，仍额外缩小约 2.98%
Y 预测约 118.60 um，实验为 118.08 um，只差约 0.44%

由此判断：

1. Y 方向的差异几乎可以由实际几何缩放和一个相机像素的量化解释。
   仿真与实验 Y 差 6.92 um，相当于 0.94 个相机像素。

2. X 方向存在明显系统性缩放。
   仿真与实验 X 差 35.28 um，相当于 4.78 个相机像素，不能只归因于采样波动。

3. 实验平顶核心 RMS 起伏约 11.02%，仿真约 1.82%；实验还存在上/下约 7.65%
   的平均强度差。PercentEnergy 取决于能量如何分布，不是纯几何边界，因此实验
   中的亮区、暗区和边界起伏会使累计到 86.5% 时的外接范围进一步变化。

4. 手动测量光阑约 557.5 x 208.0 um，大于主光斑尺寸，没有直接裁切主光斑；
   主光斑上方的亮斑也位于手动光阑之外，因此不是当前尺寸差异的主要来源。

5. 2048 计算相位裁切到 390 像素后再映射到 1024 x 1024 SLM，物理尺寸取整误差
   约 0.135%，远小于 5% 到 10% 的实验差异，不是主因。8-bit 相位量化更可能影响
   效率和均匀性，而不是单独造成接近 10% 的几何缩放。

关于输入扩束光：

仿真假设 X/Y 均为 6.5 mm 的 1/e^2 intensity diameter。此前扩束光测量结果为：

profile 1/e^2：X=5.920 mm，Y=6.236 mm
D4sigma：X=6.373 mm，Y=6.578 mm

仿真参数的定义是 1/e^2 intensity diameter，因此不能用 D4sigma 直接代替。
此前 profile 1/e^2 与仿真假设的比例为：

X=5.920/6.5=0.9108
Y=6.236/6.5=0.9594

该方向与实验中“X 缩小更多、Y 缩小较少”的现象一致。它说明实际输入振幅的
尺寸和椭圆度可能是仿真与实验不一致的重要原因。X+5/Y+5 只补偿光束与相位的
相对安装位置，不能补偿输入光束的宽度、椭圆度或强度轮廓。

现场补充信息：2026-07-15 有人调整过扩束镜的扩束部分。因此此前测得的
5.920 x 6.236 mm 不能直接代表今天实验时的真实入射光，今天的输入光尺寸可能
已经发生变化。这进一步支持“输入光束模型不一致”是当前差异的重要候选原因。

明日计划（2026-07-16）：

1. 在 SLM 入射面或与其严格等效的共轭面重新测量扩束后光斑。
2. X/Y 分别记录 profile 1/e^2 intensity diameter，这是与仿真 6.5 mm 参数直接
   对应的主指标。
3. 同时记录 D4sigma、FWHM、曝光、增益、PIXELSCALE、BINNING 和原始 bgData，
   但不要用 D4sigma 直接替代 1/e^2 参数。
4. 记录光斑是否椭圆、是否截断、中心是否偏离以及 X/Y profile，便于决定是否
   需要用实测椭圆 Gaussian 重新仿真。

当前原因优先级判断：

第一：扩束调整后真实输入光的 1/e^2 尺寸、椭圆度与 6.5 x 6.5 mm 模型不一致。
第二：真实系统 X/Y 空间映射存在约 0.93/0.95 的不同缩放。
第三：实验平顶不均匀和 BeamGage 边界像素处理使 X 的 86.5% 范围额外缩小。
第四：相机 7.38 um 像素量化，主要影响 Y 方向的一个像素级差异。
