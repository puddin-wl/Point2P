# 2026-07-16 平顶光中心空洞仿真结论

## 已完成

- 固定使用 V2 的 `phase_refined.npy`。
- 正向传播复用原项目 `src.propagation.forward_fft`，没有另建传播公式。
- V2 基准重算结果与保存的 `reconstruction_refined.npy` 相对 L2 误差为
  `9.99543e-08`，说明仿真基准复现正确。
- 实验目标使用 `20260716-1.bmData` 全部 16 帧的平均结果。
- 共完成三轮、合计 891 个 `2048 × 2048` 正向传播案例：
  - 254 个单因素案例；
  - 294 个二维椭圆输入振幅凹陷案例；
  - 343 个“实测输入振幅 + 离焦/像散/球差”组合案例。

## 实验空洞指标

- 分析核心框：`339.48 × 118.08 um`。
- 中心物理窗口：`36.90 × 36.90 um`。
- 中心窗口/核心均值：`0.7736`。
- 中间三分之一/左右区域：`0.8981`。
- 核心 RMS：`25.01%`。

## 已经在仿真中产生同类空洞

当前最接近的固定 V2 正向传播模型是二维椭圆输入振幅凹陷：

```text
amplitude dip depth = 0.60
sigma_x = 4.0 mm
sigma_y = 1.5 mm
```

结果：

```text
中心窗口/核心均值 = 0.7609
中间三分之一/左右区域 = 0.8997
核心 RMS = 20.70%
```

这已经同时复现了实验中的中心下降和 X 方向中部相对两侧变暗。对应的输入强度
形态是沿 Y 方向分裂成上下两个主瓣。参数中的 60% 是振幅凹陷，中心局部强度
相对未扰动 Gaussian 的透过率为 `(1 - 0.60)^2 = 0.16`。

该模型是“能产生实验空洞的等效输入模式”，不是对真实原因的最终认定。

## 实测入射振幅不能单独解释空洞

把 `G-光斑-1.bgData` 的实测强度直接重采样到 V2 DOE 网格，取平方根作为入射
振幅并假设平面波前，得到：

```text
中心窗口/核心均值 = 0.9727
中间三分之一/左右区域 = 0.9769
核心 RMS = 5.86%
```

因此，当前保存的实测强度分布本身不足以产生 7 月 16 日的明显空洞。

## 常见低阶波前也不能完整解释

在实测入射振幅上扫描离焦、像散和球差后，最佳粗扫描组合为：

```text
defocus = +0.40 waves
astigmatism = -0.60 waves
spherical = 0
```

对应结果：

```text
中心窗口/核心均值 = 0.8244
中间三分之一/左右区域 = 0.9965
核心 RMS = 29.42%
```

低阶波前能够形成 Y 方向的中心暗带，但没有复现实验中 X 方向中部相对两侧下降
到约 0.898 的形态，同时会产生明显过强的上下亮边。因此仅用简单离焦、像散和
球差也不够。

## 当前物理判断

仿真已经证明：固定 V2 相位在非理想输入模式下可以产生与实验相近的中心空洞，
因此不需要先假设 V2 文件损坏或 FFT/导出错误。

但 13:39 保存的 `G-光斑-1.bgData` 并没有记录到仿真最佳模型所需的明显双瓣
输入强度。剩余可能性主要是：

1. `G-光斑-1.bgData` 与 13:35 的空洞平顶光不是严格同时、同一状态测量，高功率
   模式在两次测量间变化。
2. 实际输入包含当前强度相机无法记录的高阶或局部波前相位结构。
3. 截断、不同心或像差发生在入射光测量面之后，因而没有出现在 `bgData` 中。
4. 高功率下的相机非线性、饱和或其他探测链路效应仍未通过专门曝光扫描排除。

## 后续纠正路线

1. 高功率状态下同步记录 SLM 共轭面的二维强度；不要在调节光路后再补测。
2. 最好获取输入复场。没有波前传感器时，可在相邻 2～3 个 Z 位置记录强度，
   用相位恢复求输入波前。
3. 只加载闪耀光栅并做相机轴向扫描，确认暗带是在整形前已经存在，还是由 V2
   相位与非理想输入耦合产生。
4. 得到可信的实际复输入后，把它替换当前的理想 6.5 mm Gaussian，重新运行
   MRAF/WGS，生成针对真实输入的补偿相位，而不是直接对焦面空洞做经验加亮。
