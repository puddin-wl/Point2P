# 2026-09-12 中心空洞根因更正

## 已确认根因

后续硬件排查确认，实验中观察到的中心空洞来自 **PBS 在极高功率下损坏**。
该现象属于光路硬件损伤效应，不是此前拟合所推断的球差与离焦组合。

## 对既有结论的影响

本更正取代以下文档中的物理归因和补偿建议：

- [`FINAL_CONCLUSION_20260717.md`](FINAL_CONCLUSION_20260717.md)；
- [`ADDENDUM_20260721.md`](ADDENDUM_20260721.md)；
- [`CURRENT_SCAN_RECORD.md`](CURRENT_SCAN_RECORD.md)。

此前的仿真仍能证明球差与离焦在数学上可以生成与实验相似的中心凹陷，但形貌
相似并不能证明实际系统具有对应的 Zernike 像差。因此：

- `Z40=+0.10625`、`Z20=+0.25000` RMS waves 及其扫描组不再作为中心空洞
  的补偿候选；
- 不再围绕这次空洞继续做 Zernike 拟合或系数微调；
- 原脚本、结果和日志保留，仅用于历史复现、算法测试和说明排查过程；
- 通过受损 PBS 采集的数据不应用于估计或验证系统波前像差。

## 后续验证边界

7 月 15 日 V2 整形算法基线不因本次根因更正自动失效，但它需要在健康光路中
重新验证。建议在更换或修复 PBS 后，以受控功率复测同一 V2 基线，并把 PBS
状态、入射功率和测量条件与结果一起记录。旧的空洞拟合参数不应加载到新的验证
链路中。
