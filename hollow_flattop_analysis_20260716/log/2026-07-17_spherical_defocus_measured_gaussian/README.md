## 本批次主结论

固定 V2 相位、不人为破坏 Gaussian 振幅时，标准 Zernike `Z40` 球差配合
额外 `Z20` 离焦可以产生矩形内部空洞。

第三列关键参数：

```text
Z40 = -0.10625 RMS waves
Z20 = -0.25000 RMS waves
pupil diameter = 15 mm
```

把理想 6.5 mm Gaussian 换成实测 `G-光斑-1.bgData` 后，矩形外轮廓仍然
保持，空洞继续存在，内部起伏整体更接近实验。

## 结论边界

当时结果认为“球差 + 离焦”能够解释主要空洞形貌，是有效的物理候选机制。
它还不能单独证明实验系统只存在这两项像差；实验中的上下不对称、端部增强和
剩余起伏仍可能包含其他低阶像差、偏心或实测波前效应。
