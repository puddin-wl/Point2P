# 2026-07-16 平顶光中心空洞分析

当前目录只用于分析 2026-07-16 出现的矩形平顶光中心空洞，不修改原始 V2
artifact 和 `real_test` 数据。

## 最终判断（2026-07-17）

本轮分析已经结束。最终工作结论：

> 不规则入射光斑和13–15 mm场镜入瞳截断均不是中心空洞的主要原因；
> 真正产生实验量级中心空洞的是球差，且需要与适量离焦联动考虑。

- V2 基准正向传播已经准确复现。
- `G-光斑-1.bgData` 的实测 Gaussian 入射强度直接用于 V2 正向传播时，不会产生
  实验中的明显空洞。
- 人为加入严重双瓣输入振幅可以在数学上产生空洞，但不符合当前实验判断，因此
  只作为反例保留，不作为真实原因或纠正依据。
- 标准 Zernike 球差与额外离焦的联合扫描已经在不改变 Gaussian 振幅的情况下
  产生了矩形内部空洞。
- 当前最明确的“外轮廓优先”案例为 `Z40=-0.10625`、`Z20=-0.25000`
  RMS waves：50% 外轮廓 IoU 为 `0.9927`，中心比为 `0.7734`，与实验
  `0.7736` 基本相同。
- 把同一组 Z40/Z20 应用于实测 `G-光斑-1.bgData` 振幅后，矩形 IoU 仍为
  `0.9825`，中心比为 `0.7529`、中部/两侧为 `0.8880`、核心 RMS 为
  `22.66%`；空洞保留且整体起伏更接近实验。
- 已按实际1024×1024、17 µm SLM网格进行0–1 m自由空间角谱传播。重新核对
  原始 `.bgData` 后取消了矩形ROI硬裁切；在不加入Zernike像差时，实测光斑
  在1 m处D99.9为`13.345 mm`，15 mm场镜入瞳外功率为`0.06712%`。
- 把15 mm圆孔实际乘到场镜平面后再作傅里叶变换，1 m处实测光斑的中心比仅
  改变`-0.00064`，理想Gaussian仅改变`+0.00060`；截断没有产生中心空洞。
- 进一步只用实测光斑测试14 mm和13 mm入瞳：1 m处分别截去`0.08008%`和
  `0.11999%`功率，中心比下降`0.00100`和`0.00357`，仍未形成中心空洞。
- 这证明“球差 + 离焦”是当前主导机制，但暂不等于已经唯一确定实验系统的
  全部波前像差组成。
- 最终收口记录见 `docs/FINAL_CONCLUSION_20260717.md`。

## 补充状态（2026-07-21）

- 真实 16 帧平均的 86.5% 能量尺寸为 `332.10 × 118.08 µm`，尺寸已经基本
  达标；中心比稳定在约 `0.774`，后续重点是均匀性补偿而不是继续放大尺寸。
- 12 mm 场镜入瞳仍未产生中心空洞，截断主因进一步排除。
- 同时反转主案例 Z40/Z20 符号会把中心凹陷变为中心隆起；下一阶段以
  `Z40=+0.10625`、`Z20=+0.25000` RMS waves 作为首个 SLM 补偿基准。
- 像散和彗差探索已经归档，但不进入第一轮补偿。
