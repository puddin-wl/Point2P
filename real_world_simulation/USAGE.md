# Real-World Simulation Usage

This folder is a standalone tolerance simulator for the fixed DOE phase that
was already generated by the previous refinement project. It reads the existing
`phase_refined.npy` as input and does not modify or rerun the old DOE program.

## What It Simulates

The simulator keeps the DOE phase fixed and changes only real optical/input
conditions:

- observation-plane defocus
- Gaussian beam offset on the DOE plane
- Gaussian beam size
- DOE-plane wavefront divergence/convergence
- pointing-induced focal-plane shift
- effective clear aperture
- input beam ellipticity

The default sweep range is intentionally mild. The broader original range is
still available as a stress profile.

## Main Commands

Run the default mild full sweep:

```powershell
cd E:\program\Point2P\real_world_simulation
& 'D:\software\anaconda\envs\slmrtad\python.exe' .\run_real_world_sweep.py --sweep all
```

Run one mild sweep:

```powershell
& 'D:\software\anaconda\envs\slmrtad\python.exe' .\run_real_world_sweep.py --sweep defocus
& 'D:\software\anaconda\envs\slmrtad\python.exe' .\run_real_world_sweep.py --sweep beam_offset_x
& 'D:\software\anaconda\envs\slmrtad\python.exe' .\run_real_world_sweep.py --sweep divergence
```

Run the broad stress sweep:

```powershell
& 'D:\software\anaconda\envs\slmrtad\python.exe' .\run_real_world_sweep.py --sweep all --profile stress
```

Run a fast smoke test with a centered phase crop:

```powershell
& 'D:\software\anaconda\envs\slmrtad\python.exe' .\run_real_world_sweep.py --sweep all --smoke-size 512 --no-pdf
```

## Sweep Names

Valid `--sweep` values:

```text
all
nominal
defocus
beam_offset_x
beam_offset_y
beam_size
divergence
pointing_x
pointing_y
aperture
ellipticity
```

Valid `--profile` values:

- `mild`: default, small perturbations for realistic first-pass inspection.
- `stress`: broader perturbations for finding failure boundaries.

## Output Layout

Every run creates one grouped folder:

```text
artifacts/<timestamp>_<profile>_<sweep>/
```

For `--sweep all`, the folder contains one subfolder per sweep:

```text
artifacts/<timestamp>_mild_all/
  run_effect_summary.csv
  run_effect_metrics_overview.png
  run_worst_intensity_montage.png
  defocus/
  beam_offset_x/
  beam_offset_y/
  beam_size/
  divergence/
  pointing_x/
  pointing_y/
  aperture/
  ellipticity/
```

Each sweep subfolder contains:

```text
summary.csv
summary.json
center_profiles_overlay.png
metric_trends.png
simulation_report.pdf
representative_intensity_nominal.png
representative_intensity_worst.png
```

## How To Read The Results

Start with these run-level files:

- `run_effect_metrics_overview.png`: compares the worst e^-2 efficiency and
  worst RMS nonuniformity across all deviation types.
- `run_worst_intensity_montage.png`: shows one representative worst intensity
  image for each deviation type.
- `run_effect_summary.csv`: records the worst parameter value for each sweep.

Then inspect the sweep subfolder:

- `metric_trends.png`: shows how metrics change as that parameter changes.
- `center_profiles_overlay.png`: overlays x/y center profiles for all values.
- `representative_intensity_worst.png`: shows the worst case image.
- `simulation_report.pdf`: combines the summary, trends, profiles, and images.

Important metrics:

- `efficiency_e2_percent`: energy fraction inside the measured e^-2 target ROI,
  relative to the power transmitted through the aperture.
- `rms_nonuniformity_percent`: RMS nonuniformity inside the flat target core.
- `aperture_throughput_percent`: how much of the original input Gaussian passes
  the clear aperture before renormalized propagation.
- `center_offset_x_um` / `center_offset_y_um`: 50% profile center shift from
  the expected target center.
