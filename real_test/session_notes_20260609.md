## 3. 实验传输区宽度

采用与仿真诊断一致的定义：

```text
transition_13.5_90 = 0.5 * (size13.5 - size90)
```

也就是每一侧从 `90%` 掉到 `13.5%` 的边沿宽度。

实验 raw profile 结果：

| 方向 | size90 | size13.5 | 传输区宽度 |
|---|---:|---:|---:|
| X | `292.34 um` | `328.49 um` | `18.08 um` |
| Y | `89.49 um` | `128.98 um` | `19.74 um` |

最终仿真 artifact 诊断结果：

| 方向 | 仿真传输区宽度 | 实验 - 仿真 | 相机像素差 |
|---|---:|---:|---:|
| X | `17.12 um` | `+0.95 um` | `0.13 px` |
| Y | `16.50 um` | `+3.24 um` | `0.44 px` |

结论：

- 如果按 raw profile 的强度边沿来算，实验传输区和仿真基本对得上。
- 不能据此说明振镜/场镜系统把边沿明显拉宽。
- 振镜/场镜误差更可能体现在整体偏斜、剪切、梯形畸变，而不是边沿传输区宽度。

注意：

- 早期 `flattop_size_analysis` 中的 `transition_width_um = 49.05 / 52.86 um` 来自 smoothed/clipped profile 口径。
- 这个数更适合诊断和定位，不适合直接和仿真 raw intensity profile 的边沿宽度对比。

## 4. 仿真中“传输区”的两个口径

仿真目标使用 raised-cosine edge：

```text
C(u; u0, u1) = 1                                  for u <= u0
             = 0.5 * (1 + cos(pi*(u-u0)/(u1-u0))) for u0 < u < u1
             = 0                                  for u >= u1
```

目标参数：

| 参数 | 值 |
|---|---:|
| `W50` | `330 um` |
| `H50` | `120 um` |
| `delta_x` | `15 um` |
| `delta_y` | `8 um` |
| `release_level` | `exp(-2) = 13.5%` |

设计意义：

- `delta_x/delta_y` 是围绕 50% 边界的半宽参数。
- 完整的 raised-cosine 边沿宽度为 `2 * delta`。
- X 完整边沿：`30 um`
- Y 完整边沿：`16 um`

诊断意义：

- `transition_13.5_90` 不是完整边沿，而是从 `90%` 到 `13.5%` 的单侧宽度。
- 理想 raised-cosine 模板下：

| 方向 | 理想 `90% -> 13.5%` 单侧宽度 |
|---|---:|
| X | `16.66 um` |
| Y | `8.89 um` |

最终仿真重建后：

| 方向 | `size90` | `size13.5` | `transition_13.5_90` |
|---|---:|---:|---:|
| X | `311.51 um` | `345.76 um` | `17.12 um` |
| Y | `103.04 um` | `136.04 um` | `16.50 um` |

## 6. 厂家给出 `310 x 103 um` 的反推

用户补充：厂家给出的尺寸是 `310 x 103 um`。

对多个候选算法进行反推：

### 6.1 强度阈值候选

最接近 `310 x 103` 的强度阈值候选：

| 候选口径 | X | Y | 备注 |
|---|---:|---:|---|
| 50% peak, 5 点平滑, 单像素 profile | `308.4 um` | `108.2 um` | 最接近的统一强度阈值口径 |
| 50% peak, 3 点平滑 | `306.2 um` | `107.7 um` | 也接近 |
| 50% median(flat), raw profile | `308.1 um` | `109.6 um` | X 接近，Y 偏大 |

二维 50% 阈值连通域外接框：

| 口径 | X | Y |
|---|---:|---:|
| 2D 50% threshold bbox, count pixels | `310.0 um` | `125.5 um` |
| 2D 50% threshold bbox, coordinate span | `302.6 um` | `118.1 um` |

结论：

- 2D 阈值外接框可以让 X 接近 `310 um`，但 Y 明显过大。
- 不像厂家 `310 x 103` 的来源。

### 6.2 86.5% 能量候选

ROI 内 Percent Energy 候选：

| 能量比例 | X | Y |
|---|---:|---:|
| 50% energy, 最小区间 | `155.0 um` | `59.0 um` |
| 86.5% energy, 最小区间 | `273.1 um` | `103.3 um` |
| 90% energy, 最小区间 | `287.8 um` | `118.1 um` |

重要结论：

- `86.5% energy` 可以解释 Y 方向的 `103 um`。
- 但同一口径下 X 只有 `273 um`，不能解释厂家给出的 `310 um`。

### 6.3 分别反求 X 和 Y 对应阈值

如果要求中心 raw profile 精确得到 `310 x 103 um`：

| 方向 | 目标宽度 | 需要的阈值，相对 `median(flat)` | 约等于相对峰值 |
|---|---:|---:|---:|
| X | `310 um` | `45.5%` | `38.0% peak` |
| Y | `103 um` | `65.5%` | `58.9% peak` |

3 点平滑后：

| 方向 | 目标宽度 | 需要的阈值，相对 `median(flat)` |
|---|---:|---:|
| X | `310 um` | `48.8%` |
| Y | `103 um` | `63.2%` |

结论：

- `310 x 103 um` 不能由同一个强度阈值同时定义出来。
- 也不能由一个简单的一维 `86.5% energy` 同时定义出来。
- 更像是厂家软件内部 beam width / ROI / energy enclosure / smoothing 等算法综合得到的结果。

当前最合理判断：

- X = `310 um` 很像 FWHM 或接近 50% 强度宽度。
- Y = `103 um` 很像 86.5% energy 最小区间宽度。
- 但这两者不是同一个简单算法，因此不能武断说“厂家就是 86.5% energy”。

## 7. 后续仿真放大尺寸建议

用户目标：最终交付给厂商，因此定义本身不重要，关键是让厂家软件读数达到目标要求。

当前实验/厂家读数：

- 厂家读数：`310 x 103 um`
- 目标：`330 x 120 um`

若直接按厂家读数比例校正仿真目标：

| 方向 | 比例 | 当前仿真 W50/H50 | 建议新 W50/H50 |
|---|---:|---:|---:|
| X | `330 / 310 = 1.0645` | `330 um` | `351 um` |
| Y | `120 / 103 = 1.1650` | `120 um` | `140 um` |

建议下一轮优先扫：

```text
W50 = 350, 355, 360 um
H50 = 138, 140, 142 um
```

建议先保持：

```text
delta_x = 15 um
delta_y = 8 um
release_level = exp(-2)
```

原因：

- 实验与仿真的边沿传输区宽度基本对得上。
- 当前主要误差更像是软件尺寸定义/能量包络读数偏小，而不是边沿太宽或太窄。
- 因此第一步应该扩大目标尺寸，而不是同时修改边沿参数。
