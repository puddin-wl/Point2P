# DOE 光斑误差拟合总结

## Problem 1: 长边中间内凹 ✅

- **根因**: 椭圆度 Dx > Dy（x 方向光束直径大于 y 方向）
- **物理机制**: x 方向过度照明，抢走长边中心处的 y 向能量，长边（330μm 边）中段被拉进去
- **关键发现**: 仅缩小 Dy 而保持 Dx=5.0 几乎不产生内凹；必须 Dx > Dy 才会
- **加密拟合数据**: `problem1_longedge_concavity/`
- **探索过程**: `problem1_exploration/`

## Problem 2: 长边能量缺失 + 短边倾斜 △

- **最接近假设**: H1 beam_offset_x + beam_offset_y（光斑偏离 DOE 中心）
- **排除**: H3（offset+pointing）只是光斑整体偏离 target，不是问题形态
- **状态**: 难以精确定位，暂不深入
- **数据**: `problem2/`

## Problem 3: 四条边都向内凹 ✅

- **根因**: 负离焦 + 光斑偏大
- **关键组合**: defocus = -0.25 ~ -1.0 mm + beam_size = 5.5 ~ 6.0 mm
- **物理**: 观察面在焦点之前 + 光束扩束稍大 → x 和 y 方向同时内凹
- **重要**: 纯离焦无法同时让四边内凹（x/y 方向反向）；小光斑+离焦会产生外凸
- **数据**: `problem3_rerun/`（含线条样式标注：实线=正离焦，虚线=负离焦）
